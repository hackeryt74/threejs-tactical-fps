Emberline is a round-based tactical FPS that runs offline in the browser: first-person gunplay with recoil and spread that punish firing on the move, bots that patrol routes, hold sites and react to what they see and hear, a spike to plant and defuse, and money earned each round to spend in a buy menu. Four guns, a frag grenade, a dusk freight yard with three lanes and two bomb sites — all built from three.js geometry and WebAudio synthesis, no network requests, no build step.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
